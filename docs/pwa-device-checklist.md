# 手机端 PWA 实机自检清单

> 目的：家长中心重构上线后，在真实手机上逐项确认线上产品行为。
> 线上地址：**https://today.itonghao.cn**（线上与 localhost 存储不互通，务必用线上域名测）。
> 建议设备：iPhone（Safari）+ Android（Chrome）各测一次。
> 准备一个可收短信的测试手机号；家长中心 PIN 为 **1234**（仅防误触）。

## 1. 四页面可用

- [ ] 「今天」页正常渲染，任务卡上的书包/图书/闹钟等雪碧图图标无错位。
- [ ] 「计划」「成长」「奖励」三个标签页均可打开且渲染正常。
- [ ] 首页插画（星星伙伴等 WebP）显示正常。

## 2. 家长中心分层与 PIN 下沉

- [ ] 打开家长中心，首屏能看到三层说明：不登录也能用（记录存当前设备）/ 建议登录长期保存 / 可安装到手机桌面。
- [ ] 首屏未登录时只显示「登录并开启云端同步」按钮，点击后才展开手机号 / 验证码表单。
- [ ] 登录与安装引导**不要求** PIN。
- [ ] 进入「孩子与成长 / 奖励规则 / 技能管理 / 使用偏好 / 记录与数据」任一二级模块时要求输入 PIN；输错有提示，输对可进入。
- [ ] 「退出家长账号」在受 PIN 保护的「记录与数据」里；已绑定云端账号时不显示文件恢复入口。

## 3. PWA 安装引导（iOS 与 Android 各测）

- [ ] 未安装状态下，家长中心安装区按环境显示指引：iOS 提示用 Safari「分享 → 添加到主屏幕」；Android 显示安装按钮或菜单指引。
- [ ] （可选）微信内打开线上地址，提示「在浏览器打开」。
- [ ] Android 上点击「安装「今天我做主」」能调起系统安装；安装完成后回到页面显示「✓ 已经放到桌面」。
- [ ] 桌面图标显示正常（maskable 图标未被裁切），点击图标以独立窗口（无浏览器地址栏）打开。
- [ ] iOS 添加到主屏幕后，从图标打开同样以独立模式运行，并显示「✓ 已经放到桌面」。

## 4. 完成挑战与防重复

- [ ] 在今天页完成一个挑战，星星立即入账（有飞星动画），钱包数字上涨。
- [ ] 同一天重复完成同一挑战会被阻止，不重复加分。
- [ ] 刷新页面后完成状态与星星数保持。

## 5. 云端同步跑通

- [ ] 家长中心用手机号（自动带 +86）验证码登录成功。
- [ ] 登录后后台自动同步，界面上**没有**“立即同步”按钮。
- [ ] 在另一台设备（或无痕窗口）用同一手机号登录，历史记录能通过云端事件账本恢复。
- [ ] 断网状态下孩子操作不被弹窗阻断；恢复网络后本地待传事件自动补传。
- [ ] 已登录状态下退出登录入口可用（在「记录与数据」内）。

## 6. 离线与弱网

- [ ] 安装为 PWA 后，开启飞行模式再打开应用，不白屏（Service Worker 缓存生效）。
- [ ] 弱网环境下打开不出现长时间白屏（导航请求 2.5s 超时回退缓存）。

## 7. 成长足迹产品边界

- [ ] 「成长足迹」趋势文案只说「记录到的自主完成更多了」，不出现“能力提升 / 进步多少 / 退步”等断言。
- [ ] 无连续打卡、排行榜、完成率评分、红黄绿警告。
- [ ] 历史记录只读，家长无法修改过去的记录。
