# 今天我做主 · 绘本视觉版

适合一年级孩子的自主力成长网页原型。

## 本地运行

在解压后含有 dist 文件夹的目录执行：

```bash
python -m http.server 8080 -d dist
```

Windows 也可以使用 `py -m http.server 8080 -d dist`。
打开 http://localhost:8080 。无需安装 npm 依赖。
双击 dist/index.html 可以预览页面，但建议用本地 HTTP 服务体验和保存记录。

## 文件结构

- dist/index.html：网页入口
- dist/styles.css：绘本视觉、贴纸卡片、移动端布局和动态效果
- dist/app.js：任务、计划、星星、能力、奖励和家长设置
- dist/*.webp：网页实际加载的三张插画（由 assets/ 的原图转换而来）
- assets/growth-art.png：原 A4 成长板图标素材，CSS 按雪碧图坐标裁切
- assets/storybook-scene.png：小星星与小兔的绘本场景
- assets/star-friend.png：透明底小星星伙伴
- .openai/hosting.json：原 Sites 项目的配置
- ASSETS.md：新增插画的制作说明

## 本版视觉优化

1. 首页采用绘本插画，金色小星星作为视觉伙伴。
2. 蓝、黄、粉色任务贴纸卡，放大图标并标注“我做完了”。
3. 一天的安排采用彩色步骤卡，支持上下移动。
4. 成长页采用徽章册形式，展示已获得的等级与下一级进度。
5. 奖励屋采用票券样式，区分待兑换与已领取的奖励。
6. 完成任务后短暂播放彩纸和星星反馈；遵循系统“减少动态效果”设置。
7. 保留所有原有任务、规则和本地记录格式。

## 使用

孩子自己选 1–3 项挑战、安排顺序、完成后如实记录。
自主完成得 1 星；提醒后完成记录练习，不扣已有星星。
家长入口数字为 1234，仅防误触，不属于安全认证。
家长可以修改昵称、升级次数、鼓励语、奖励价格、确认兑现与技能毕业。

## 记录说明

沿用 localStorage 的 self-growth-v1 数据键。在同一浏览器、同一站点地址更新资源后，原有记录会继续使用。
本地地址与原线上地址属于不同来源，记录不会自动互通；清理浏览器数据会删除记录。
代码包不包含任何孩子的使用记录。当前版本没有账号系统或跨设备同步。
